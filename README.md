
# QuickNotes

QuickNotes is a simple browser-based note-taking application that helps users create, organize, search, and manage personal notes. Users can assign categories to their notes and keep their notes saved locally in the browser, even after refreshing the page.

## Features

- Add notes with text and categories.
- Organize notes into Personal, Work, and Study.
- Display the date and time each note was created.
- Delete individual notes.
- Search notes without case sensitivity.
- Validate empty notes and notes longer than 200 characters.
- Display the total number of notes.
- Save notes using browser localStorage.
- Restore saved notes after refreshing the page.
- Responsive layout for mobile and desktop screens.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Browser localStorage

## How to Run Locally

1. Clone the repository or download the project files.
2. Open the `quicknotes-app` folder in Visual Studio Code.
3. Open `index.html` in your browser, or use the Live Server extension.
4. Add notes, select categories, search, and delete notes as needed.

No server or database is required. Notes are stored in the browser's localStorage.
